## Limits

CI verified full cross-platform package hashes; the separate local check verified
metadata and the downloaded Linux compiled archive, not all public installer
bytes. No real provider/account login, Windows 10/11 NSIS installation, FUSE
acceptance, target OS keyring or installed N-to-N+1 upgrade was tested. The unpacked
app's updater reports unsupported as expected; that is not installed-update
acceptance. No actual user database migration, Cloudflare setup or live R2 upload
was performed. These remain beta limitations, not stable acceptance claims.
