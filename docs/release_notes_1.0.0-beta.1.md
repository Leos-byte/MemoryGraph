# MemGraph 1.0.0-beta.1 - Calico

## 大版本更新

- 全新 Calico 亮色界面：奶油白工作台、暖白阅读区、杏橘主要操作、炭黑文字，统一语义化设计 Tokens。
- 优化知识图谱、Markdown 阅读、代码与表格、设置、模板管理、回收站、登录输出和更新窗口；支持窄屏抽屉、键盘焦点及减少动态效果。
- 新增更新方式：仅手动、自动检查（默认）、自动检查并下载。后台检查在启动 15 秒后开始，此后每 6 小时进行。
- 更新安装需要确认重启，验证签名和完整文件摘要，并成功备份 SQLite 数据；普通退出不会自动安装。
- 保留现有地图、节点、关联、模板、回收站、模型与自定义设置；不强制迁移旧模型，也不复制 Codex 登录凭据。

## 下载与升级

Windows x64 使用 setup.exe 安装版，或 ZIP 解压版；Linux x64 使用 AppImage，或 tar.gz 解压版。

**Windows 安装版和 Linux AppImage 支持应用内更新。ZIP/tar.gz 解压版需从 GitHub 下载并手动替换程序，继续使用原有数据目录。**

测试版更新需要在设置中启用“接收 Beta 更新”。旧版本可手动检查获取本版本；新增后台策略需先升级至本版本。升级前建议手动备份数据。

## 测试与限制

这是 1.0 大版本的首个测试版，不代表稳定版人工验收已经完成。自动化覆盖临时数据、模拟模型及模拟签名升级，不消耗模型额度。

Windows/Linux 构建、测试、打包和发布签名由 GitHub Actions 检查；实际成功结果以关联工作流和项目测试记录为准。Windows 10/11 实机安装、AppImage/FUSE、真实已安装版本 N-to-N+1 替换、系统密钥环和真实模型账号仍需人工验收。

Windows 尚无 Authenticode 发布者签名，可能出现未知发布者提示。发布包及更新元数据有独立 Ed25519 签名，两者不是同一种签名。

反馈入口支持浏览器提交 GitHub Issue，或打开邮件客户端联系 leo.oceanai@gmail.com；不会自动上传知识内容或密钥。R2 镜像仍未启用，GitHub Releases 是下载及更新来源。
