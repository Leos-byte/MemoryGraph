## Defaults And Compatibility

New profiles use `gpt-6.1-terra`; loading an existing settings file preserves its
model exactly. Switching explicitly from a non-OpenAI provider to ChatGPT login
uses that same OpenAI fallback. Ordinary OpenAI model changes preserve the key;
changing provider origin still clears the previous provider's credential.

API-key OpenAI requests continue to use Responses with `store: false`. GPT-6
presets do not add temperature, top-p, log-probability or custom reasoning fields.
DeepSeek presets keep the documented compatible Chat Completions route. Selecting
a new preset does not enable browsing, tools, image upload, or multimodal input.

ChatGPT login still delegates to the installed official Codex CLI. Use a current
CLI and a model supported by the signed-in account/workspace. MemGraph does not
update Codex globally, grant model access or copy its credentials. OpenAI and
DeepSeek API keys remain separate from ChatGPT login; provider usage may be billed.

## Verification Scope

Tests use temporary profiles and mock fetch/Codex behavior. They verify exact IDs,
request protocol/body, persistence, key isolation, bilingual aliases and settings
layout, not successful paid calls or entitlement on a real account.
