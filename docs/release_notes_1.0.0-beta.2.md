# MemGraph 1.0.0-beta.2 - Snow Leopard

## 新增雪豹皮肤

- 在“设置 > 通用 > 皮肤”选择“雪豹 Snow Leopard”，无需刷新，立即生效并自动保存，重启后恢复。
- Calico 三花猫仍为默认皮肤，原有配色、布局和交互保持不变；可随时切换回来。
- 切换皮肤只保存皮肤，不提交模型、密钥、目录等其他未保存设置；保存失败恢复原皮肤并提示错误。
- 雪岩白、冷灰与冷杉绿覆盖图谱、阅读、代码、表格、模板、回收站、更新与通知；主按钮、深色输出链接和状态色保持可读对比。
- 主题注册表支持后续扩展；旧配置和未知主题值安全回退到 Calico，启动首屏应用已保存的主题，不新增数据库迁移或依赖。

## 安装与更新

Windows x64：setup.exe 安装版或 ZIP；Linux x64：AppImage 或 tar.gz。

Windows 安装版和 Linux AppImage 支持应用内检查、下载及确认重启安装。测试版需要开启“接收 Beta 更新”。ZIP/tar.gz 解压版需从 GitHub 手动下载并替换程序，保留已有数据目录。

升级前建议备份数据。更新签名公钥与既有版本一致；本版不删除历史发布包、备份或用户数据。

## 验证与限制

本地验证覆盖 141 项单元测试、21 项桌面流程、56 项发布工具测试及打包启动；Windows/Linux 发布工作流结果以关联记录为准。

系统原生 Tooltip、文件对话框及系统绘制的下拉弹出层仍使用系统样式。Windows 安装包没有 Authenticode 发布者签名，系统可能提示未知发布者；独立 Ed25519 更新签名不是 Authenticode。真实 Windows 10/11 安装、FUSE/系统密钥环及已安装版本的跨版本替换仍需人工验收。

GitHub 是发布及更新来源；R2 镜像未在本次启用。反馈请使用软件内 GitHub 反馈，或邮件入口 leo.oceanai@gmail.com；不会自动上传知识内容或凭据。
