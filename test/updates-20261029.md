# Manual And Automatic Updates - 2026-10-29

## Scope

User request: add manual and automatic updates. Implemented locally on top of main `f02330d`; no dependency, package-version, release/tag, hosted asset, update public key, R2 or credential changes. The executable still reports `0.2.0-beta.4` and is explicitly a development build, not the public beta.4 package. No push, PR or publication was requested/performed in this task.

## Behavior

- `Settings.updateMode`: `manual`, `notify` (default for new and old profiles), `download`. Existing models, data directory and stable/beta selection are preserved.
- Supported Windows installed NSIS and Linux AppImage builds check 15 seconds after startup/policy changes and then every six hours. Manual mode and unsupported unpacked/development builds schedule no background requests. Closing the app disposes timers/listeners.
- Manual entry points in File and saved Settings; unsupported builds offer GitHub Releases in the browser. Network/update failures expose retry plus the same fallback.
- Background checks/downloads retain visible header state. Auto-download starts only after signed metadata verification. Ready packages remain ready when the dialog is reopened or another check is requested. After an app restart, discovery/cache verification occurs again rather than trusting persisted readiness.
- Downloaded bytes are reverified before restart; explicit confirmation is mandatory, normal quit never installs, and a successful SQLite backup is required before calling the installer. Active generation is cancelled before backup. Backup/verification failures do not launch the installer.
- Concurrent checks/downloads/installation are guarded; channel changes invalidate old candidates and in-flight results. Downgrade is explicitly disabled after assigning the library channel (its setter otherwise enables downgrade). Asynchronous installer errors unlock retry.
- New controls/statuses/confirmation are bilingual. Beta releases require enabling Receive beta updates; selecting a background policy does not silently opt stable users into prereleases.
